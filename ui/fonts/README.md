# Fonts

Proposed series typography (framework §11, "[DECIDE font]"):

| File | Use |
|---|---|
| `AlegreyaSC-Medium.ttf` | Display: titles, banners (small caps) |
| `Alegreya-Variable.ttf` | Book text: Codex, rule names, game-over lines |
| `AlegreyaSans-Regular/Medium/Bold.ttf` | Interface: labels, buttons, menus |

Alegreya and Alegreya Sans (Huerta Tipográfica) are under the SIL Open Font
License 1.1 (`OFL-*.txt`), free for commercial games. Both cover Latin
Extended and Cyrillic, so 9 of the 12 launch languages (EN, PT-BR, ES, FR,
DE, IT, RU, PL, TR); Simplified Chinese, Japanese and Korean need a Noto
Sans CJK fallback. Downloaded from github.com/google/fonts on 2026-11-03.
